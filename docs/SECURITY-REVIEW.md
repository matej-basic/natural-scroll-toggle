# Security review

Date: 2026-10-21. Version reviewed: 0.2.0, before the first commit and the first release.

## Scope

Everything in the repository except build output (`.build/`, `build/`): the menu bar app (`Sources/NaturalScrollToggle`), the `ScrollCore` library and its tests, `build.sh`, the one-line installer `install.sh`, the Homebrew cask, both GitHub workflows, `compose.yaml`, `Makefile`, `.gitignore`, the README and the other top-level files. The research notes `docs/RESEARCH.md` and `docs/BREW.md` were read for background and checked for personal data only.

Out of scope: notarization. The author has no Apple Developer ID, so the app is signed ad hoc and the install routes remove the quarantine flag. That choice is accepted; finding 1 states what it costs.

## Method

1. Read every file in scope line by line.
2. Searched the tree for secrets and personal data (the home directory path, the e-mail account name, `gho_`, `ghp_`, `github_pat`, `token`, `password`, `secret`, `serial`) and for APIs that read input, ask for permissions, start processes or use the network.
3. Tested the installer's building blocks on this Mac (macOS 27) with throwaway files in a scratch directory: `xattr -dr` on trees with and without the attribute and with symlinks; `ditto -x -k` on crafted archives with `../` entries, absolute paths, and a symlink followed by an entry written through it; `shasum -a 256 -c` on malformed and SHA-1 sums files.
4. Fed every byte prefix of the fixed `install.sh` (5,261 prefixes of a 5,262-byte file) to `bash` with all external commands replaced by logging stubs, to check what a cut-off `curl | bash` download can run.
5. Checked the regular expression added to the release workflow against good and hostile tag names.
6. Ran the tests, the three linters, `./build.sh`, `codesign --verify` and `brew style` after the fixes (results are in the hand-off notes, not repeated here).

Severity is rated by what an attacker gains and what they need first. A finding that needs write access to the repository is rated by what it adds on top of that access, which is usually nothing.

## What a compromised app could do

A replaced or backdoored `NaturalScrollToggle.app` runs as the logged-in user, outside any sandbox, with quarantine removed, so it could read and change whatever that user can reach (home directory files outside the privacy-protected folders, the user's preferences, network access, a login item via `SMAppService`); it could not become root without the user's password, and it could not read keystrokes, the screen or protected folders such as Documents or Desktop without macOS first showing a permission prompt, because the genuine app holds none of those permissions. The genuine app, if an attacker controls only its inputs (device names, the distributed notification, its own preferences, `argv`), can be made to flip natural scrolling or redraw its menu, and nothing more.

## Residual risk

- Notarization: none. Users trust the GitHub account and the release workflow directly, Apple never scans the binary, and a bad release cannot be revoked by Apple. Finding 1.
- `curl | bash` trust: running the installer trusts whatever is on `main` at that moment, fetched over TLS from GitHub. The hash in `SHA256SUMS` protects the transfer, not the source. Anyone who can push to `main` or publish a release (the owner, a stolen token, the release job itself) can ship code that runs with the user's rights. Findings 2 and 12.
- Private API: `setSwipeScrollDirection` and `CGSSetSwipeScrollDirection` are undocumented. A macOS update can remove them (the app falls back to writing the preference) or change them (the app may crash or set the wrong value). There is no security exposure in that, only breakage. Finding 19.
- Homebrew trust: the cask lives in a personal tap. Users who run `brew trust` on the whole tap also trust any future cask added to this repository.
- Runner images: releases are built on `macos-latest`, whose toolchain changes without notice. A compromised GitHub-hosted image would affect every project that builds there, not only this one.
